# Yale UI Component Library

The Yale UI Component Library (UICL) is an open set of Web Components for Yale web pages and apps.
The components are plain Custom Elements. They need no framework.
Their styles come from the YaleSites design tokens in `@yalesites-org/tokens`.
Each component renders into a closed shadow DOM, so page styles do not leak in.
Every tag starts with `ycl-`, for example `<ycl-button>` and `<ycl-alert>`.

## Who it is for

UICL is for developers who build Yale web pages and apps.
It works in plain HTML and alongside any framework.

## How to load it

UICL is published to npm as `yale-ui-cl`, and the jsDelivr CDN serves it.
You need no build step and no token.

### In a plain HTML page

Add one stylesheet and one script. The stylesheet holds the design tokens, base typography and component styles.
`@1` gets the latest 1.x release; pin a full version such as `@1.2.0` if you want the page never to change.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/yale-ui-cl@1/dist/yale-ui-cl.css">
<script type="module" src="https://cdn.jsdelivr.net/npm/yale-ui-cl@1/dist/yale-ui-cl.js"></script>
```

Here is a whole page you can copy into a file and open in a browser:

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>My UICL page</title>
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/yale-ui-cl@1/dist/yale-ui-cl.css">
    <script type="module" src="https://cdn.jsdelivr.net/npm/yale-ui-cl@1/dist/yale-ui-cl.js"></script>
  </head>
  <body>
    <main>
      <ycl-heading level="1">Welcome to my page</ycl-heading>
      <ycl-accordion>
        <ycl-accordion-item>
          <span slot="heading">What is UICL?</span>
          <p>A set of Web Components for Yale web pages and apps.</p>
        </ycl-accordion-item>
        <ycl-accordion-item>
          <span slot="heading">Do I need a framework?</span>
          <p>No. The components are plain HTML tags.</p>
        </ycl-accordion-item>
      </ycl-accordion>
      <ycl-button variant="filled" radius="soft" href="https://www.yale.edu">Visit Yale</ycl-button>
    </main>
  </body>
</html>
```

To load only some components, keep the stylesheet and swap the full bundle for one script per component.
The file name is the tag with the `ycl-` prefix removed:

```html
<script type="module" src="https://cdn.jsdelivr.net/npm/yale-ui-cl@1/dist/button.js"></script>
```

### With a bundler

```bash
npm install yale-ui-cl
```

Load the stylesheet once, then the full bundle or single components:

```js
import 'yale-ui-cl/style.css';
import 'yale-ui-cl';         // every component
import 'yale-ui-cl/button';  // or just one
```

## How this Storybook is organized

Components follow atomic design. The sidebar groups them by tier:

- **Introduction**: this page.
- **Atoms**: small single-purpose parts, such as buttons, links, inputs and icons.
- **Molecules**: groups of atoms that form a pattern, such as alerts, cards, tabs and banners.

Each component page has live examples, a controls panel for its attributes, and the HTML source.
